# メモルピ / Memorupi

Mac・Windows向けの、メモとデスクトップ付箋のアプリです。
このリポジトリはアプリ本体と更新情報の配布専用です。ソースコードは公開していません。

## 現在の配布

現在の安定版・自動更新対象は [0.3.10](https://github.com/BB999/memorupi-releases/releases/tag/v0.3.10) です。Mac Apple Silicon版とWindows x64版を配布しています。Intel Mac版・Windows ARM64ネイティブ版の配布はまだありません。

[最新版をダウンロード](https://github.com/BB999/memorupi-releases/releases/latest)

Windowsは `Memorupi_<バージョン>_windows_x86_64.exe` をダウンロードして実行します。ユーザー単位のインストーラーで、WebView2が未導入の場合はインターネット接続が必要です。初回インストール後、今後の更新はアプリ内から適用できます。

Windows版はMac上でクロスビルドし、配布ファイルと更新用署名を検証しています。以前のWindows版の正常動作とMarkdown版の同期成功はユーザーから報告を受けています。0.3.10のWindows実機での起動・保存・今回の実際の更新と再起動は未確認です。AuthenticodeによるOS署名は未実施のため、SmartScreen等の警告が出る場合があります。

Mac版はDeveloper ID署名・Apple公証をまだ行っていません。他のMacでの初回起動時にGatekeeperの警告が出る場合があります。OS署名・公証を行っていない個人用配布です。
更新ファイルにはTauri Updater用の署名を付けていますが、これはAppleの署名・公証やWindowsのAuthenticode署名とは別です。

## 更新

更新対応版では、起動時と常駐中の6時間ごとに新しいバージョンを確認します。
設定または常駐メニューの「更新を確認」からも確認できます。
「保存して更新・再起動」を選ぶと、すべてのウィンドウのメモを保存してから更新します。
保存失敗・入力の競合・変換中・応答待ち超過の場合は、入力を残して更新を中止します。

0.3.5は保存方式をSQLiteから端末内のMarkdownへ変更しました。旧SQLiteのメモ・付箋・同期状態は自動移行せず、新しいローカル保存から始めます。旧メモが必要な場合は更新前に設定からJSONバックアップを保存し、新版で読み込んでください。旧DBファイル自体は削除しません。Google同期は新版で再接続が必要で、Driveに残っている旧メモは接続後に受信します。クラウドデータやOSの認証情報は削除しません。

0.3.5以降のMarkdown版からは、既存のローカルメモと同期設定を引き続き使います。0.3.10を既に手動で起動している場合は同じ版なので、更新通知は出ません。Macでは新版への入替え直後にKeychainのアクセス許可を求められる場合があります。

メモは端末内の `notes/*.md` に保存し、付箋状態と同期情報は `.memorupi/state.json` で管理します。通常の過去版履歴は作りません。Markdownの直接編集と新規ファイルの追加に対応しますが、同じメモをGUIと外部エディタで同時保存しないでください。保存先は設定画面で確認できます。

0.3.10では、本文より上のボタンから見出し・太字・箇条書き・番号付きリスト・チェック項目を入力できます。MarkdownプレビューとHTTP/HTTPSリンクの標準ブラウザー起動に対応し、本文とプレビューの行間をコンパクトにしました。

枠なし・角丸の独立付箋は端・角のドラッグで拡大縮小でき、文字サイズも連動します。縮小はその時の表示文字幅に左右同じ余白を加えた幅で止まり、短いメモには操作ボタン用の最小幅180pxを残します。手動サイズと文字倍率は再起動後も保持し、手動変更後は本文編集や操作欄の表示でサイズを変えません。手動変更前は本文に合わせた高さ調整を利用できます。マウスを乗せたときだけ表示する操作欄は本文と重ならない別行表示です。

同じGoogleアカウントでのDrive同期には、別途Desktop OAuth設定JSONと本人の認可・メモの紐づけ確認が必要です。iPhone版は未実装です。
公開する配布ファイルに利用者のメモや認証情報は含みません。
